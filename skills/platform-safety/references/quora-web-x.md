# Quora, web forums and X

## Quora

- Questions stay open for years, so age does not close a thread. Check that a recent answer does not already solve the problem.
- Quora asks authors to disclose affiliation in the answer. Use a natural first-person sentence.
- The app cannot read the comment state of a Quora page, so it flags the thread with unverified_comment_state. The owner checks the page.
- Posting is manual only.

## Web forums and communities

- The harvester accepts a page only when it looks like a discussion: a known discussion host, a forum-style host name or a thread-style path. It rejects pricing pages, product pages, listicles and comparison pages.
- Read the forum's rules page and its signature or promotion rules before a reply.
- Posting is manual only.

## X

- [official] X's automation rules ban unsolicited automated replies and bulk replying. A person must write and send each reply.
- The harvester reads thread indexers only. This source is weak and mostly lists threads by creators, not customers. Use X leads as insight.
- Posting is manual only. The app prepares the text and the owner sends it from the linked account.
- Keep replies short. Write like the owner's timeline: same case, same punctuation, same emoji habit.

## Linked accounts

For each platform the owner links the handle of an existing account. The app stores the handle and the posting mode. It reads public data where the platform allows it. It never stores a password or a session cookie.
