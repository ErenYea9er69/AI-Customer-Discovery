# Disclosure patterns

If you work on, own or run the product you mention, say so in the reply. Say it in a normal first-person sentence inside the reply. The reader must see it without effort. The code replaces {product} with the product name when it builds a reply.

Why this matters. The FTC Endorsement Guides (16 CFR Part 255, updated 2023) treat an unexpected material connection as something the audience must learn about, clearly and in the post itself. Reddit's own guidance says to be open about a connection to a product you mention. A disclosure also keeps trust: readers forgive a founder who says so and punish one who hides it. This file is not legal advice.

## Approved phrases

State the fact of the connection. An apology for bias is optional. Use it in about one reply in three, not in every reply. The code picks four phrases per reply and the model writes a close variant.

- I built {product} for this exact problem.
- I work on {product}, so weigh my view accordingly.
- Full disclosure, I'm the founder of {product}.
- I'm on the {product} team.
- My team makes {product}, so I'm biased here.
- I make {product}, which is one option for this.
- Bias warning: I run {product}.
- I started {product} after hitting this problem myself.
- Disclosure, I work at {product}.
- I'm one of the people behind {product}, so keep my bias in mind.
- I maintain {product}.
- I'm the solo dev behind {product}.
- Heads up, {product} is mine.
- I wrote {product} for my own use first, then opened it to others.
- I own {product}, so treat this as one opinion among many.
- I'm the maker of {product}.
- I founded {product} two years ago.
- I contribute to {product}, so I'm not neutral.
- I'm on the {product} team and I use it for exactly this.
- Yes, I'm affiliated with {product}: I build it.
- I build {product} for a living.
- {product} is my project, so I'm not a neutral voice.
- I work on {product}. It's one option, and here's where it stops.
- My day job is {product}.
- I run the company behind {product}.
- I write the code for {product}.

## Where to put the sentence

| Position | Use when |
| --- | --- |
| Right before the product name | Default. The reader learns the connection as they meet the product. |
| Right after the product name | Short replies. |
| Opening clause | The whole reply centers on the product. |
| Last sentence | Only when the product mention is the last idea. Never as a detached footer. |

## Rules

1. The sentence is in the reply text, not only in the profile.
2. Use first person. Say what you do: build, work on, run, own, founded, maintain, contribute.
3. Use plain words. Vary the phrase across replies and across accounts you control.
4. One disclosure per reply is enough. Do not repeat it.
5. If someone asks "do you work there?", answer yes and repeat the fact.
6. State the connection that is true. "Founder" for a founder, "work on" for staff. Do not understate it.

## Never use

- A hashtag such as #ad, #sponsored or #partner.
- A legal footer such as "Disclaimer: the author is affiliated with the product."
- "Not sponsored" or "not an ad" when you work on the product.
- The disclosure only in your profile bio.
- "As a user of {product}" when you are on the team.
- "Disclosure: I am affiliated with {product}." as a stiff stand-alone line. It is allowed by the code as a fallback, but it reads like a form. Prefer a phrase from the list above.
- A disclosure in a separate comment a reader may never open.
- A made-up role, such as "satisfied customer", when you are staff.
